# تقرير تنفيذ عارض Flow والقيم التلقائية

This project By Gogo & Disha ®

التاريخ: 2026-11-09. فرع التنفيذ: `feature/flow-viewer-inline-values`. طلب المراجعة: [PR #1](https://github.com/Disha-Galal/dishafile/pull/1). لم يحدث دمج في `main`.

## ما تم تنفيذه

- التعرف على TNetstring من بايتات الملف قبل مسار النص، بما يشمل الملفات بلا امتداد مثل `flows (2)` وامتدادات `.flow` و`.mitm` و`.mitmproxy`، مع أخطاء عربية للملفات التالفة.
- محلل Kotlin داخل `core` لكل وسوم TNetstring المطلوبة، مع حفظ ترتيب القواميس والترويسات المتكررة، ودعم سجلات متتالية وغياب الاستجابة وبيان الأنواع غير المدعومة.
- قائمة تدفقات مختصرة، وتبويبات نظرة عامة والطلب والاستجابة والمستخرج. يُفتح الطلب تلقائيًا، وتظهر **القيم الحقيقية بجوار المفاتيح فورًا** دون زر Analyze. تظهر حقول Form وJSON قبل بيانات الطلب العامة، وتُطوى القائمة عند اختيار التدفق لتوفير مساحة للقيم على الهاتف.
- Query وForm مع فك `%` و`+` بصورة صارمة، وJSON متداخل ومصفوفات دون فقد `false` أو `null` أو `0` أو القيم الفارغة أو الأرقام الكبيرة أو المفاتيح المكررة. يدعم Multipart حقول النص وأسماء الملفات وأحجامها فقط، دون إرسال محتوى الملفات الثنائية إلى الواجهة.
- فك أجسام identity وgzip وdeflate ضمن الحدود، واحترام charset وBOM وCRLF. عند الفشل تبقى الترويسات وتظهر رسالة ومعاينة Hex محدودة؛ لا تُضاف محارف بديلة بصمت.
- استخراج محلي للإيميلات والهواتف المصرية والدولية والروابط مع المصدر والنوع والعدد، وبحث مؤجل 120 ms بالمفتاح أو القيمة من الصفوف المحللة، ونسخ القيمة أو `key=value` أو المسار عند طلب المستخدم فقط.
- خيار إخفاء الأسرار للعرض والنسخ فقط. تُحجب معاينات الأجسام النصية أيضًا منعًا لتسرب الأسرار من النص الخام. يظل الأصل والقيم المحللة كما هما، والتصدير الصريح يحتوي القيم الحقيقية حتى مع تفعيل إخفاء العرض.
- جلسة مستقلة للقراءة فقط خارج مسار حفظ النص. تصدير التدفق المحدد إلى JSON جديد عبر SAF مع منع URI الأصلي والتحقق بالقراءة بعد الكتابة. لا تصدير أو مشاركة أو نسخ تلقائي، ولا مسودات Flow تحتوي بيانات الملف.
- المعالجة الثقيلة في عامل خلفي، وإلغاء طلب التفاصيل السابق عند تغيير التدفق أو فتح ملف جديد، وتجاهل النتائج القديمة، وذاكرة مؤقتة لتدفقين. العرض 100 صف في الدفعة مع تحميل المزيد.
- الحفاظ على المحرر وSAF والمسودات والنسخ الاحتياطية والترميزات وJSON/JSONL وGZIP. بُنيت أصول المحرر المحلية وأُضيفت إلى Git؛ لا CDN ولا API ولا LLM داخل التطبيق ولا صلاحية INTERNET.

## الحدود العملية

الملف 40 MiB، السجل 16 MiB، 4096 تدفقًا، عمق 48، وإجمالي 200 ألف عقدة. فك الجسم حتى 1 MiB، ومعاينة النص 64 ألف حرف. حتى 5000 صف وميزانية مليوني حرف لكل من العرض والاستخراج، و1000 تطابق نصي. عند تجاوز الميزانية يُذكر أن بعض الصفوف لم تُعرض، دون تغيير الأصل. البحث محلي داخل التدفق المحدد والصفوف المتاحة، وليس بحثًا شاملًا في كل بايتات الملف.

التصدير هو صفوف العرض والمعاينات المحدودة **للتدفق المحدد**، وليس تفريغ mitmproxy كاملًا قابلًا لإعادة الاستيراد. Brotli وZstd وHAR غير مدعومة، كما لا تُفك رسائل WebSocket أو TCP/UDP. الأجسام الثنائية لا تُحوّل إلى نص مُختلق. `HTTP 200` وحده لا يثبت نجاح تسجيل الدخول.

## الاختبارات والنسخة التجريبية

يجري تحديث هذا القسم بالنتائج النهائية وروابط artifacts بعد اكتمال تشغيل GitHub Actions المطابق للكود الأخير. تشغيل البناء الأول [42540057933](https://github.com/Disha-Galal/dishafile/actions/runs/42540057933) نجح في مرحلة البناء، واختباراته على Android 13 قيد المتابعة وقت كتابة المسودة؛ ليس هذا ادعاءً باكتمال التشغيل النهائي.

## ما لم يُختبر على هاتف حقيقي

لم يتوفر ملف المستخدم الحقيقي `flows (2)`، ولم تُحفظ بيانات شبكة حقيقية في Git أو سجلات الاختبار. جميع اختبارات Flow تستخدم fixture صناعيًا من أربعة تدفقات، وفيه `demo@example.test` و`sample123` فقط لأغراض التحقق. لم يُختبر OPPO فعلي أو Telegram أو كل مزودي Downloads أو Android 8 على جهاز حقيقي. منتقي إنشاء الملف وأخطاء امتلاء القرص وانتهاء grants واختلافات IME والمزودات تحتاج خطوات [القبول](ACCEPTANCE.md).

## تثبيت النسخة على الهاتف

من تشغيل Actions النهائي افتح Artifacts، ونزّل `Disha-FileKit-debug-APK` وفك ZIP، ثم ثبّت `app-debug.apk`. تحتاج Android 8 أو أحدث وWebView حديثًا. النسخة Debug للتجربة؛ قد تختلف مفاتيح توقيع Actions عن النسخة المثبتة. إذا رفض أندرويد التحديث، صدّر المسودات والملفات المهمة أولًا قبل إزالة النسخة القديمة؛ إزالة التطبيق تمسح مسوداته ونسخه الخاصة.

فعّل وضع الطيران وافتح `flows (2)` مباشرة من SAF. اختار POST وافتح الطلب؛ يجب ظهور `username` و`password` وقيمهما الفعلية دون تحليل يدوي. راجع الاستجابة والمستخرج والبحث والنسخ والإخفاء، وقارن أصل الملف قبل وبعد. لا تشارك التفريغ أو القيم الحساسة في صور أو تعليقات PR.

## توفير الاستخدام

استُخدمت أوامر Shell محلية واختبارات محددة وإصلاحات مبنية على النتائج، دون subagents أو خدمات مدفوعة أو مفاتيح API، ودون إضافة أي تكلفة تشغيل للتطبيق. بقيت إصدارات الأدوات المثبتة كما هي، مع رفع إصدار التطبيق إلى 1.1.0 للتمييز بين النسخ.
